# איך להוסיף שאלות למבחן «מבוא לסוציולוגיה של החינוך»

## מקור האמת
- **דף העזר:** `assets/sociology/remembrance-sheet.pdf` (2 עמודים)
- **מאגר גולמי (לעריכה):** `questions-sociology.raw.json`
- **מאגר לריצה (נוצר אוטומטית):** `questions-sociology.js`

## הוספת שאלה
1. פתחו `questions-sociology.raw.json`.
2. הוסיפו אובייקט בסוף המערך:

```json
{
  "topic": "דורקהיים ומבוא לסוציולוגיה של החינוך",
  "sheetSection": "1.4 דירקהיים",
  "page": 1,
  "question": "נוסח השאלה…?",
  "correct": "התשובה הנכונה במלואה",
  "wrong": [
    "מסיח אמין 1",
    "מסיח אמין 2",
    "מסיח אמין 3"
  ],
  "explanation": "הסבר קצר שמלמד — מצביע על מה שכתוב בדף העזר"
}
```

3. הריצו:

```bash
node tools/rebuild-sociology.mjs
```

הסקריפט:
- ממספר מחדש את ה-`id`
- מערבב את מיקום התשובה הנכונה (A/B/C/D) בעקומה אנטי-תבניתית
- כותב את `questions-sociology.js`

## `sheetSection` — קישור לדף העזר
השתמשו בכותרות מהדף, למשל:

| עמוד | דוגמאות ל-sheetSection |
|------|-------------------------|
| 1 | `1.1 חברה`, `1.2 חקר החברה האנושית`, `1.4 דירקהיים`, `1.5 חינוך כתחום ידע`, `1.6 סוציולוגיה של החינוך`, `2.1 סוציולוגיה כמדע`, `2.3 …פונקציונלית`, `2.4 גישת הקונפליקט`, `3 תרבות…`, `4 מרכיבי תרבות` |
| 2 | `5 חיברות הגדרה`, `5.1 בידוד חברתי`, `5.5 סוכני חיברות`, `6 ריבוד…`, `6.2 סוגי מוביליות`, `6.4 ריבוד לפי הגישות` |

במבחן, אחרי תשובה נכונה מוצג קישור ל-PDF + מספר עמוד + שם הסעיף.

## ערבוב תשובות
- **בבנק:** `rebuild-sociology.mjs` מאזן A/B/C/D ומונע דפוסים קלים.
- **בזמן ריצה:** `app.js` מערבב שוב את סדר השאלות ואת אות התשובה הנכונה בכל התחלה חדשה.

## טיפים למסיחים
- מסיחים צריכים להישמע סבירים (בלבול בין פטליסטית/אנומית, הון תרבותי/חברתי, Role Strain/Conflict).
- אל תסמנו את התשובה הנכונה תמיד כ-A ב-JSON הגולמי — השדה `correct` הוא **טקסט**, והסקריפט ממקם אותו.
